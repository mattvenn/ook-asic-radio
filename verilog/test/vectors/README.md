# Test vectors from the bit-exact model

Generated by `model/export_vectors.py` from `model/radio.py`; `summary.json` lists each scenario's expected events and toggles. Regenerate after any change to the model.

## RX digital: `rx_<name>.npz`
| Field | Meaning |
|---|---|
| `comp` (uint8[n]) | Comparator bit presented at sample *i* |
| `trim` (uint8[n]) | Trim DAC code the RTL must output after processing sample *i* (starts at 128 before sample 0) |
| `events` (int[k,2]) | Detection events (chip time, max score), in order |
| `toggles` (int[m]) | Chip times at which the LED toggles (LED starts at 0) |
| `code` | The RX's DIP code |

The digital is deterministic given the comparator bits, so **replaying `comp` open-loop must reproduce `trim`, `events` and `toggles` exactly**. The noisy scenarios' `comp` streams come from the closed loop with the analog behavioural model.

### Timing contract (10 MHz clock, counted from reset release)
- **Sample tick:** every 130 clocks; sample *i* is taken at clock 130·*i*. The RTL samples its comparator input at the tick; the testbench changes `comp` between ticks.
- **Trim servo:** on each tick, trim += 1 if comp else −1, saturating at 0 and 255.
- **Chip counter:** increments on ticks where *i* mod 8 == 0, *before* that sample is processed. Event and toggle times are this counter.
- **Phase windows:** 4 phases p ∈ {0, 2, 4, 6}. Phase p's window of 8 samples ends on ticks where (*i* mod 8 − p) mod 8 == 7.
  - Chip bit = count > 4, or (count == 4 and the last sample is 1).
  - The bit shifts into that phase's 127-bit register (bit 0 = newest).
- **Score:** after each shift, the number of *j* in 0..126 with reg[126 − *j*] == code chip *j*. The RTL may compute it sequentially, but it must finish before that phase's next shift, 8 samples (1040 clocks) later.
- **Events:**
  - A score ≥ 97 opens an event at the current chip count, unless one is already open; the event's score is the maximum score while open.
  - The event closes at the first tick where chip count ≥ open time + 8.
- **Pairing:** when an event closes at time *t*:
  - If *t* ≥ holdoff end, and |*t* − prev − 191| ≤ 2 or |*t* − prev − 382| ≤ 2 for either of the two previous events → toggle the LED. Then set holdoff end = *t* + 9615 and clear the history.
  - Otherwise, append *t* to the history (keep the last 2).

## TX: `tx_codes.npz`
| Field | Meaning |
|---|---|
| `chips` (uint8[128,127]) | Chip sequence of each code (1 = carrier on) |
| `lfsr2` (uint8[128]) | LFSR2 start state after `code` steps from the all-ones seed (code 127 = M1 only) |

- **LFSR1:** taps (7,3). **LFSR2:** taps (7,3,2,1). Both are Fibonacci, output = stage 7 (MSB of the state).
- **A send:** 3 bursts, each 127 chips followed by 64 off-chips. One chip = 1040 clocks.
